# bmahOS

An experimental operating system project.

## Target

Primary target hardware:

- HP Stream Notebook PC 11
- Intel Celeron N2840
- 2 GB RAM
- x86_64
- UEFI

## Goals

- Lightweight
- Headless/server-oriented
- 24/7 operation
- Remote administration
- Networking
- IoT and robotics support
- System and network monitoring
- Open source
